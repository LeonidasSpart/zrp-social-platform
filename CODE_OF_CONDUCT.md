# Code of Conduct

ZRP is built around the idea that a social platform can be safer and more
human. That standard applies to the people building it, not only to the
product.

This Code of Conduct applies to everyone taking part in this repository —
contributors, maintainers and anyone commenting on an issue, pull request
or review.

## Scope

It covers project spaces: issues, pull requests, code review, commit
messages, code comments, and any other communication about this project.
It also applies when someone is representing the project elsewhere.

Conduct inside the ZRP product itself is governed by the ZRP Terms of
Service and Community Guidelines, not by this document.

## Expected behaviour

- Be direct and be civil. Technical disagreement is welcome; contempt is
  not.
- Review the code, not the person. Say what is wrong and what would be
  better.
- Assume competence and good faith. Ask before concluding.
- Accept that a maintainer may decline a change, and say why once rather
  than relitigating it.
- Respect confidentiality. Unreleased work, security reports and private
  information stay private.
- Give credit for other people's work.

## Unacceptable behaviour

- Harassment, intimidation, or sustained disruption of discussion.
- Insults, personal attacks, or demeaning comments.
- Discriminatory language or conduct, including on the basis of age,
  disability, ethnicity, gender identity or expression, nationality,
  physical appearance, race, religion, sex, or sexual orientation.
- Sexualised language or imagery, and unwelcome sexual attention.
- Publishing someone's private information without their explicit
  permission.
- Deliberately introducing insecure, malicious or misleading code.
- Publicly disclosing a security vulnerability before it has been
  remediated, contrary to [SECURITY.md](SECURITY.md).

## Reporting

Report a concern to the repository owner, or through the ZRP contact
page at https://zrp.one.

Reports about a **security vulnerability** go to **security@zrp.one** as
described in [SECURITY.md](SECURITY.md), not to a public issue.

Reports are handled discreetly. Do not raise a conduct complaint about a
specific person in a public issue or pull request thread.

## Enforcement

Maintainers are responsible for clarifying these standards and may take
any action they judge appropriate, including editing or removing
comments, commits, issues and pull requests, and withdrawing repository
access.

Enforcement is proportionate: most matters are resolved with a private
word. Repeated or serious breaches may result in removal from the
project.

## Attribution

This Code of Conduct is written for the ZRP project. It is informed by
common practice in the wider software community, including the
[Contributor Covenant](https://www.contributor-covenant.org), but it is
not a copy of it and imposes no obligations beyond those stated above.
